# ISM backup and recovery mapping

Authority: [ASD Information Security Manual](https://www.cyber.gov.au/resources-business-and-government/essential-cyber-security/ism). Use the organisation's approved ISM edition, system classification and applicability decision. Exact control IDs are deliberately not asserted without verifying their edition-specific wording.

| ISM assessment topic | Implementation contribution | Feature and test evidence | Required external evidence / gap |
| --- | --- | --- | --- |
| Backup scope, frequency and retention | Local workspace snapshots and scheduled policy values | [Policy fields](../user/policies.md), [repository scope/exclusion tests](https://github.com/jusso-dev/bunker/blob/main/crates/bunker/tests/repository.rs), scheduler at `crates/bunker/src/scheduler.rs` | Business-approved RPO/RTO, full asset coverage, operating history and enforced retention; retention pruning not implemented. |
| Recovery procedures and testing | Plan preview, confirmation, file verification and temporary-directory restore | [Runbook](../user/restore.md), [runbook smoke](https://github.com/jusso-dev/bunker/blob/main/packaging/scripts/smoke_restore.py), [stale/tampered restore tests](https://github.com/jusso-dev/bunker/blob/main/crates/bunker/tests/repository.rs) | Independent operator exercise, measured recovery time, agent boot/MCP connectivity, clean-machine and live-provider recovery. |
| Confidentiality and key custody | Host-side encrypted objects and passphrase-wrapped data key | [Security model](../user/security.md), [crypto authentication tests](https://github.com/jusso-dev/bunker/blob/main/crates/bunker/src/crypto.rs), [wrong-key/rotation tests](https://github.com/jusso-dev/bunker/blob/main/crates/bunker/tests/repository.rs) | Approved cryptographic profile, key lifecycle and custody assessment. No KMS, Key Vault or escrow integration. |
| Integrity and recovery-copy protection | Authenticated reads, verify-before-restore, encrypted replication/readback | [Storage guide](../user/storage.md), [transport tests](https://github.com/jusso-dev/bunker/blob/main/crates/bunker/src/storage.rs) | Live provider immutability/deletion tests, independent secondary copy, geographic resilience and backup-admin separation. |
| Access control and auditability | Restricted MCP tools, tenant roles, approval records and evidence export | [Team guide](../user/teams.md), [API auth/approval/export tests](https://github.com/jusso-dev/bunker/blob/main/control-plane/tests/api.test.ts), [MCP restrictions test](https://github.com/jusso-dev/bunker/blob/main/crates/bunker/tests/repository.rs) | Production identity/mTLS, privileged host controls, durable tamper-evident audit storage and audit review process. |
| Location and service-provider assurance | Region labels and provider endpoint configuration | [Residency guide](residency.md), [configuration rejection tests](https://github.com/jusso-dev/bunker/blob/main/crates/bunker/src/storage.rs) | Contractual/technical location evidence for all data and metadata; labels alone enforce nothing. |

For each applicable control, add the verified identifier, exact obligation, assessed system boundary, owner, evidence artifact/commit, test date, result and remediation due date to the organisation's register. No ISM certification, accreditation, IRAP assessment or Authority to Operate is implied by this mapping.
